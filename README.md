# 💥 Boomfy

Boomfy is an arcade browser game where players use customizable stickman characters, advanced weaponry, and destruction physics across any web page environment with pixel art parallax backgrounds.

## ✨ Features
- **Stickman Skins:** Cyber Reaper, Inferno Oni, Astral Phantom, Blood Sovereign, Solar Emperor, and Classic Striker.
- **Weapon Arsenal:** Heavy Magnum, Hyper Vector, Combat Sweeper, Titan RPG, Hyperion Railgun, Dragon Firestorm, Cluster MIRV Nuke, Apex Drone Swarm, Singularity Core, and Celestial Arcana.
- **Parallax Environments:**
  - 🌆 **Neo Cyber City** (Synthwave cyberpunk metropolis)
  - 🌲 **Mystic Forest** (Misty mountain pine forest with dynamic parallax)
  - 🌙 **Moonlit Samurai** (Moonlit pagoda and cherry blossom mountain)
- **Local Web Proxy & Physics Engine:** Smooth real-time canvas rendering with physics and weapon recoil.

## 🚀 Getting Started

### Prerequisites
- Python 3.10+

### Run Locally
```bash
python server.py
```
Open your browser and navigate to:
```
http://localhost:3001
```
